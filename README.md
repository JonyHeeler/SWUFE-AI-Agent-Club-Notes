### 也可以请 AI Agent 帮你打开

下载并解压整个仓库，用你常用的本地 AI Agent 打开这个文件夹，把根目录的 [**AGENTS.md**](AGENTS.md) 拖给它，再说：

> 帮我运行鲸鲸自习室基础版，并告诉我代码分别负责什么。

也可以换成你感兴趣的项目。Agent 会按说明检查环境、协助运行和解释代码；它需要能够访问这份源码所在的本地文件夹。

### 运行前的小准备

静态网页可以直接打开；Python 示例按各项目的 `requirements.txt` 安装依赖，建议使用 Python 3.12 或更新版本。三维展示需要 Node.js，具体步骤见项目 README。仓库只保存源码与必要资源，运行环境由使用者自行安装。

两个 API 示例的密钥均为 `YOUR_DEEPSEEK_API_KEY`，需要在本地填写自己的密钥与准备账户额度；提交或分享代码前，请恢复占位符。鲸鲸自习室面向电脑使用。

## 我们是谁

### AI 智能体 + 协会

西南财经大学 AI 智能体 + 协会，是背靠计算机与人工智能学院的学生社团。

我们的愿景是**“立足西财，推广智能体普及”**。从智能体的使用与制作出发，连接财经与不同专业的知识、创意和行业实践，探索垂类智能体，也逐步拓展具身智能和 AI 硬件相关的工程实践。

[去协会官网看看 →](https://jonywang.xyz/AgentClub/index.html)

### 奇点工作室

奇点工作室是计算机与人工智能学院的学生组织，前身是西南财经大学经济信息工程学院的官网项目组，后发展为面向学院同学的技术交流与提升平台。

工作室现分为算法部、技术部和行政部，欢迎全校对计算机技术感兴趣的同学，并将学科竞赛作为重点发展目标。

2026 年秋季学期，两个组织开始合作，开展统一的技术培训与内容共创。我们希望一起学习、一起实践，也把探索过程分享给下一位同学。
