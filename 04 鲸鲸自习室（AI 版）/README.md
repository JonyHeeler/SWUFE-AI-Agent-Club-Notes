# 鲸鲸自习室（AI 版）

基于自用 AI 版原样整理；仅将 `config.js` 的密钥替换为 `YOUR_DEEPSEEK_API_KEY`，原人设与模型配置保留。

在本地 `config.js` 填写自己的 DeepSeek 密钥，再双击 `index.html`。不需要安装依赖或启动本地服务。未填写密钥时可以打开页面，AI 对话不可用；真实发送会联网并消耗账户额度。

普通便签增改删、番茄钟及总结规划由原程序处理。删除普通便签仍需确认；XCPC 白便签保留原有保护。每次请求只带固定提示、当前输入及当前板子状态。

这是电脑端课堂示例。数据保存在当前浏览器，清理浏览器数据可能丢失记录。请保留同目录的完整字体、图片和 `FONT-LICENSE.txt`。

本例按原设计在浏览器中明文使用密钥，仅供本人本地练习。上传前必须恢复占位符；不要把填入真实密钥的目录发布到公共网页。
