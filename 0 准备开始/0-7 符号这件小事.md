# 0-7 符号这件小事

代码看起来和教程一模一样，却怎么也运行不了？有时，问题就藏在一个逗号、一对引号里。

对人来说，`;` 和 `；` 很像；对电脑来说，它们是两个不同的字符。**编程时，符号也必须写对。**

## 1. 全角、半角，中文、英文

**全角字符**在常见排版中通常占一个汉字的宽度；**半角字符**通常更窄。例如，全角括号 `（ ）` 和半角括号 `( )`，看起来相似，但不是同一组字符。

中文标点与全角符号不是完全相同的概念。例如，中文常用的弯引号 `“ ”`，和代码里的直引号 `"` 也不同。

初学时，先记住：**C++、Python 等语言的代码语法，通常使用英文半角符号**。不要只凭“长得差不多”判断。

| 代码里常用的符号  | 容易误输入的符号    |
| --------- | ----------- |
| 括号 `( )`  | `（ ）`       |
| 逗号 `,`    | `，`         |
| 分号 `;`    | `；`         |
| 冒号 `:`    | `：`         |
| 双引号 `" "` | `“ ”`、`＂ ＂` |
| 单引号 `' '` | `‘ ’`、`＇ ＇` |
| 点号 `.`    | `。`、`．`     |
| 等号 `=`    | `＝`         |
| 减号 `-`    | `－`、`–`、`—` |

有些字体会把它们显示得很接近。尤其是引号、等号和减号，复制代码时也要留意。

## 2. 中文可以写在哪里？

**中文通常可以写在字符串和注释里**。用来组织代码结构的括号、引号、分号等，则要使用语言要求的符号。

例如，下面是一行 C++ 代码：

```cpp
std::cout << "你好，AI 智能体 + 协会！"; // 输出一句中文
```

- 包住文字的 `" "` 是英文半角双引号。
- 引号里面的 `你好，AI 智能体 + 协会！` 是要输出的内容，可以使用中文标点。
- 末尾的 `;` 是英文半角分号。
- `//` 后面是注释，可以用中文解释代码。

下面这种写法就有问题：

```cpp
std::cout << “你好，AI 智能体 + 协会！”；
```

外层引号和末尾分号都变成了中文符号。**要改的是代码的符号，不是把引号里的中文也全部换掉。**

## 3. 怎样减少这类失误？

写代码前切换到英文输入。就这么简单。



遇到报错时，先看看报错位置及其前面的代码：括号是不是半角？引号是不是直的？C++ 语句末尾是不是英文分号？一个小符号，可能就是问题所在。
