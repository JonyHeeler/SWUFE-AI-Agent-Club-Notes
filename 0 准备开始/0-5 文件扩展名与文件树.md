# 0-5 文件扩展名与文件树

刚开始学习编程，你很可能先遇到一个看起来很简单、却经常让人卡住的问题：

> “我的文件在哪里？”

下载的资料不知道放在哪里，双击文件不知道该用什么软件打开，保存了代码却找不到它。想向同学求助，又只能说：“就是电脑里的那个文件。”

要把这些事情说清楚，我们先认识电脑存放文件的方式。这一节会介绍文件与文件夹的区别、文件名后面的后缀有什么用、常见文件应该怎样打开，以及怎样通过文件树和路径找到文件。

学完后，希望你既能找到自己的文件，也能准确告诉别人：“它是什么文件，放在哪个文件夹里。”

本文主要以 Windows 为例，使用 `D:\code\hello` 作为示例文件夹的位置。阅读时，可以打开文件资源管理器，对照自己的电脑看看。如果你的文件放在其他盘或文件夹里，把示例地址换成自己的实际位置即可。

## 1. 文件、文件夹和路径，分别是什么？

**文件（file）**用来保存具体内容。照片、视频、文章、代码，都可以保存在文件里。

**文件夹（folder）**用来组织文件，也可以包含其他文件夹。在编程和终端里，它通常叫作**目录（directory）**。本节中的“文件夹”和“目录”指的是同一种东西。

例如，我们在 `hello` 文件夹里创建 `src` 文件夹，再把 `main.cpp` 放进去：

```text
hello 文件夹
└── src 文件夹
    └── main.cpp 文件
```

那么，怎样告诉别人这份资料在哪个盒子里？这就要用到**路径（path）**：它是描述文件或文件夹位置的地址。

### 文件资源管理器上方的地址栏，就是在显示位置

按 `Win + E` 打开文件资源管理器，进入一个文件夹。窗口上方通常会出现类似这样的地址栏：

```text
此电脑 > 学习 (D:) > code > hello > src
```

“学习”只是这个磁盘的示例名称。点击地址栏的空白处，或按 `Ctrl + L`，通常就能看到并复制文字形式的路径：

```text
D:\code\hello\src
```

它表示**你正在查看的文件夹**。如果里面有一个 `main.cpp` 文件，那么文件的完整路径就是：

```text
D:\code\hello\src\main.cpp
```

逐段看：

| 部分         | 含义                     |
| ---------- | ---------------------- |
| `D:\`      | D 盘的根目录，也就是这个盘最上层的位置   |
| `code`     | D 盘里面的文件夹              |
| `hello`    | `code` 里面的文件夹          |
| `src`      | `hello` 里面的文件夹         |
| `main.cpp` | `src` 里面的文件，完整文件名包含扩展名 |

**文件名回答“它叫什么”，路径回答“它在哪里”。**不同文件夹里可以都有一个 `main.cpp`，所以只告诉别人文件名，不一定能找到你说的那一份。

## 2. 文件扩展名：先把隐藏的后缀显示出来

`main.cpp` 中，`main` 是名字的主体，最后的 `.cpp` 是**文件扩展名（file extension）**，也常叫作“文件后缀”。

扩展名通常提示文件类型，也会影响 Windows 默认用什么应用打开它。例如：

- `笔记.txt`：通常是纯文本文件。
- `教程.md`：通常是 Markdown 文件。
- `main.cpp`：通常是 C++ 源代码文件。
- `main.exe`：通常是 Windows 可执行程序。

Windows 的常见默认设置会隐藏已知文件类型的扩展名，因此 `main.cpp` 可能只显示成 `main`。对于学习编程的同学，**建议一直显示文件扩展名**，才能看清自己创建、下载和打开的是什么文件。

### 在 Windows 中显示文件扩展名

1. 按 `Win + E`，打开文件资源管理器。
2. **Windows 11**：点击“查看”→“显示”→勾选“文件扩展名”。
3. **Windows 10**：点击“查看”，在“显示/隐藏”区域勾选“文件扩展名”。
4. 回到文件列表，检查文件名后面是否出现了 `.txt`、`.md`、`.cpp` 等后缀。

下图展示了 Windows 11 的“显示”菜单，“文件扩展名”左侧出现勾选标记，就表示已经开启。

![Windows 11 中勾选“文件扩展名”](0-5%20图片/01-file-extensions.png)

不同版本的界面可能略有区别。

值得注意的是，**改后缀只会改名字，不会自动转换文件内容。**把 Word 文档从 `.docx` 改成 `.pdf`，不会得到 PDF；把 `main.cpp` 改成 `main.exe`，也不会得到能运行的程序。前者需要导出，后者需要编译。

## 3. 常见文件类型：应该怎么打开或使用？

不需要一次背完这张表。遇到不认识的文件，先看完整后缀，再判断你是要**阅读内容、编辑内容，还是运行程序**。

### 日常资料

| 扩展名                   | 通常是什么             | 怎么打开或使用                                              |
| --------------------- | ----------------- | ---------------------------------------------------- |
| `.txt`                | 纯文本               | 用记事本或 VS Code 阅读、编辑                                  |
| `.md`                 | Markdown 文档       | 用 MarkText 阅读排版后的内容，用 VS Code 编辑源码，也可以在 GitHub 网页中阅读 |
| `.pdf`                | PDF 文档            | 用浏览器或 PDF 阅读器阅读                                      |
| `.docx`               | Word 文档           | 用 Word 或 WPS 打开、编辑                                   |
| `.pptx`               | 演示文稿              | 用 PowerPoint 或 WPS 打开、放映                             |
| `.xlsx`               | 电子表格              | 用 Excel 或 WPS 打开、编辑                                  |
| `.csv`                | 常见的逗号分隔数据文件，本质是文本 | 用 Excel 查看表格，也可以用 VS Code 查看原始文本                     |
| `.png`、`.jpg`、`.jpeg` | 图片                | 用照片应用或图片查看器打开                                        |
| `.mp3`、`.wav`、`.mp4`  | 音频或视频             | 用支持相应格式的播放器播放                                        |
| `.zip`、`.7z`、`.rar`   | 压缩包               | 用系统支持的解压功能或 7-Zip 等工具解压，再使用里面的文件                     |

压缩包可以像文件夹一样被浏览，但它仍然是一个文件。**下载代码压缩包后，先把整个项目解压，再用 VS Code 打开解压后的文件夹**，让源代码、图片和配置文件保持原来的位置关系。

### 编程时常见的文件

| 扩展名                            | 通常是什么         | 怎么打开或使用                                    |
| ------------------------------ | ------------- | ------------------------------------------ |
| `.c`、`.cpp`                    | C / C++ 源代码   | 用 VS Code 等编辑器修改，再交给编译器编译                  |
| `.h`、`.hpp`                    | C / C++ 头文件   | 用编辑器查看，供其他源代码包含和使用，通常不单独运行                 |
| `.py`                          | Python 源代码    | 用编辑器修改；安装 Python 后，可以用 `python main.py` 运行 |
| `.html`                        | 网页文件          | 用浏览器查看效果，用编辑器修改源码                          |
| `.json`、`.yaml`、`.yml`、`.toml` | 常见的配置或数据文件    | 用 VS Code 等文本编辑器查看、编辑，由对应的软件读取             |
| `.log`                         | 日志            | 通常用文本编辑器查看，帮助排查运行问题                        |
| `.exe`                         | Windows 可执行程序 | 双击或在终端中运行；命令行程序适合在终端里运行，方便看到输出             |
| `.msi`                         | Windows 安装包   | 启动安装向导，安装软件                                |
| `.bat`、`.ps1`、`.sh`            | 命令脚本          | 用编辑器阅读；分别由 CMD、PowerShell、Bash 等对应环境执行     |

运行程序、安装包和脚本时，应确认来源可信。它们会执行操作，和阅读普通文档不同。

如果双击文件后打开了不合适的应用，可以右键选择“打开方式”，再选择合适的工具。**双击时打开什么，取决于系统设置的默认应用；文件图标变化不代表内容被转换了。**

例如，右键一个 Python 文件，在“打开方式”里选择 Visual Studio Code，就可以查看和编辑它的代码。你电脑上的应用列表会根据已安装的软件有所不同。

![右键文件，通过“打开方式”选择 Visual Studio Code 等应用](0-5%20图片/02-open-with.png)

对 C++ 来说，先记住这个过程：

```text
main.cpp（你编写的源代码）
        ↓ 编译
main.exe（Windows 上可以运行的程序）
```

## 4. 文件树：把项目的结构画出来

一个项目往往不只有一个文件。为了让别人迅速看懂结构，我们会把文件夹和文件按层级排列，画成**文件树（file tree）**。

例如，下面是本节示例项目在编译完成后的结构：

```text
D:\code\hello\
├── README.md
├── src\
│   └── main.cpp
├── data\
│   └── input.txt
└── build\
    └── main.exe
```

读文件树时，看缩进和连接线：

- `README.md`、`src`、`data`、`build` 都直接放在 `hello` 里面。
- `main.cpp` 放在 `src` 里面。
- `input.txt` 放在 `data` 里面。
- `main.exe` 放在 `build` 里面。

`src` 是 source 的常见缩写，用来放源代码；`data` 放数据；`build` 放编译产物。这些是常见命名习惯，你需要自己创建这些文件夹，它们不会因为名字特殊就自动出现。

我们把 `D:\code\hello` 称为这个项目的**项目根目录**。它是项目最外层的文件夹，和 D 盘的根目录 `D:\` 不是同一个位置。

图中的 `├──`、`└──` 和 `│` 只是画图符号，不是文件名。这里在文件夹名字后加上 `\` 帮助辨认；有些文件树也会用 `/`，或者不标记。

VS Code 左侧的“资源管理器”，展示的就是你打开的项目文件树。建议通过“文件”→“打开文件夹”打开整个 `hello`，方便一起看到代码、数据和其他资料。

下图是一个实际项目的文件树。点击文件夹左侧的小箭头，可以展开或收起里面的内容；缩进越深，表示所在的层级越深。例如，图中的 `calculator.py` 位于 `backend` 文件夹中的 `similarity` 文件夹里。

## 5. 绝对路径和相对路径

### 绝对路径：把完整地址写出来

**绝对路径（absolute path）**从文件系统的根位置开始，给出完整地址。在本节的 Windows 示例里：

```text
D:\code\hello\src\main.cpp
```

不管你当前在哪个文件夹，这个地址都指向 D 盘里同一个位置。文件夹本身也有绝对路径，例如 `D:\code\hello\src`。

macOS / Linux 中的绝对路径通常从 `/` 开始，例如：

```text
/Users/xiaoming/code/hello/src/main.cpp
```

绝对路径适合明确指定本机上的位置。但同学的项目不一定放在同一个地方；如果代码里写死你的地址，换一台电脑就可能找不到文件。

### 相对路径：从一个起点出发

**相对路径（relative path）**描述的是“从某个起点出发，怎么走到目标位置”。

例如：

```text
./src/main.cpp
```

逐段拆开：

| 部分         | 含义                     |
| ---------- | ---------------------- |
| `.`        | 作为起点的当前目录              |
| `/`        | 路径分隔符，分开每一层名字          |
| `src`      | 当前目录里面的 `src` 文件夹      |
| `main.cpp` | 这个文件夹里面的 `main.cpp` 文件 |

所以，`./src/main.cpp` 就是：**从当前位置出发，进入 src 文件夹，再找到 main.cpp。**

常见写法还有：

| 写法                  | 含义                                      |
| ------------------- | --------------------------------------- |
| `.` 或 `./`          | 当前目录                                    |
| `..` 或 `../`        | 当前目录的上一层目录                              |
| `./main.cpp`        | 当前目录里的 `main.cpp`                       |
| `src/main.cpp`      | 通常和 `./src/main.cpp` 指向同一位置，省略了开头的 `./` |
| `../data/input.txt` | 先回到上一层，再进入其中的 `data`，找到 `input.txt`     |

路径里的 `.` 和扩展名里的点用途不同；`..` 是两个连续的点，表示上一层。它们都不是要你创建一个叫“点”或“点点”的文件夹。

**写出路径，不会自动创建文件或文件夹。**如果 `src` 里面没有 `main.cpp`，工具仍然找不到它。

Windows 常用反斜杠 `\`，所以也会看到 `.\src\main.cpp`；macOS / Linux 通常用正斜杠 `/`。本节的 PowerShell 和 C++ 文件路径示例可以使用 `/`。不同工具对分隔符的支持可能不同，先按对应教程的写法使用。



向同学或 AI 求助时，尽量提供：文件树、当前工作目录、完整命令，以及原样复制的报错。这样，“我的文件在哪里？”就能变成一个可以明确定位和解决的问题。
