# 0-2 电脑上的常见截图方式

遇到报错、界面异常或需要展示操作结果时，请直接使用电脑截图。截图比手机拍屏幕更清楚、更完整，也方便搜索文字、放大细节和整理资料。

## 截图前先记住三件事

1. **只截有用的内容。** 报错时要保留完整报错文字、相关窗口标题和必要上下文，不要只截一句“失败”。
2. **保护隐私。** 截图前检查姓名、学号、手机号、聊天记录、密码、API Key、Cookie、文件路径中的真实姓名等信息。
3. **确认图片清楚。** 提交前打开图片看一遍，确保文字能读、方向正常、没有被聊天软件过度压缩。

## Windows 截图

### 方法一：截取指定区域（最推荐）

按下：

```text
Windows + Shift + S
```

屏幕会变暗，顶部出现截图工具栏。最常用的是第一个“矩形截图”：

1. 按住鼠标左键；
2. 框选需要的区域；
3. 松开鼠标；
4. 截图会自动复制到剪贴板；
5. 在微信、QQ、飞书或文档中按 `Ctrl + V` 直接粘贴。

如果需要保存成文件，点击屏幕右下角出现的截图通知，再点击保存按钮。

### 方法二：截取整个屏幕并自动保存

按下：

```text
Windows + Print Screen
```

部分键盘上写作 `PrtSc`、`PrtScn` 或 `Print Scr`；笔记本电脑可能需要同时按 `Fn`。

截图通常保存在：

```text
图片\屏幕截图
```

### 方法三：截取当前窗口

先点击要截图的窗口，再按：

```text
Alt + Print Screen
```

截图会复制到剪贴板，按 `Ctrl + V` 即可粘贴。这个方法适合只展示某个软件窗口，避免把整个桌面一起截进去。

### 方法四：使用“截图工具”

在开始菜单搜索“截图工具”并打开。它适合：

- 延时截图，例如截取下拉菜单；
- 对截图进行简单标注；
- 手动选择保存位置；
- 录制一小段屏幕操作。

## macOS 截图

### 方法一：截取指定区域（最推荐）

按下：

```text
Command + Shift + 4
```

鼠标会变成十字光标：

1. 按住触控板或鼠标；
2. 框选需要的区域；
3. 松开后自动截图；
4. 图片默认保存在桌面。

框选过程中按 `Esc` 可以取消。

### 方法二：截取整个屏幕

按下：

```text
Command + Shift + 3
```

截图默认保存在桌面。

### 方法三：截取单个窗口

按下：

```text
Command + Shift + 4
```

接着按一下空格键，光标会变成相机。点击目标窗口即可截图。

### 方法四：打开截图控制面板

按下：

```text
Command + Shift + 5
```

可以选择截取整个屏幕、窗口或指定区域，也可以录屏。在“选项”中可以修改保存位置和设置倒计时。

### 只复制、不保存文件

在上述快捷键中额外按住 `Control`，截图会复制到剪贴板。例如：

```text
Control + Command + Shift + 4
```

随后可按 `Command + V` 粘贴到聊天软件或文档中。

## 截图怎么选

| 需求 | Windows | macOS |
| --- | --- | --- |
| 截取指定区域 | `Windows + Shift + S` | `Command + Shift + 4` |
| 截取整个屏幕 | `Windows + Print Screen` | `Command + Shift + 3` |
| 截取单个窗口 | `Alt + Print Screen` | `Command + Shift + 4`，再按空格 |
| 打开完整截图工具 | 搜索“截图工具” | `Command + Shift + 5` |
| 粘贴剪贴板图片 | `Ctrl + V` | `Command + V` |

## 提问时怎样截图

一张有效的报错截图，通常应该包含：

- 使用的软件或网页名称；
- 你执行的命令或操作；
- 完整的报错文字；
- 报错前后几行必要内容；
- 系统时间或步骤顺序（问题与时间有关时）。

不要只发一张截图然后问“为什么不行”。请配上一句话，例如：

> 我在 Windows 11 的 PowerShell 中运行 `python main.py`，期望程序启动，但出现下图报错。我已经确认 Python 可以正常运行。

## 常见错误

- **用手机拍屏幕：** 图片倾斜、反光、模糊，还可能拍到无关隐私。请直接截图。
- **截图范围太小：** 只截最后一行报错，缺少真正的原因。请保留完整错误信息。
- **截图范围太大：** 把整个桌面和聊天记录都发出来。请只保留必要区域。
- **截图后找不到文件：** Windows 优先使用 `Windows + Shift + S` 后直接粘贴；macOS 默认到桌面查找。
- **快捷键没有反应：** 检查是否需要按 `Fn`，或确认快捷键没有被其他软件占用。
