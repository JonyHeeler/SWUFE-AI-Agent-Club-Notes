# 0-6 使用命令行控制电脑

平时，我们通过点击图标、拖动文件、打开菜单来操作电脑。其实，你也可以直接输入一行文字，让电脑帮你做事。

这种方式就叫作**使用命令行**。例如，打开一个文件夹、运行一段代码、安装一个 Python 库，都可以通过命令完成。

这一节主要以 Windows 为例。先认识 PowerShell 和 CMD，顺便听一段计算机往事，再学会打开命令行、使用基础命令，最后玩一点没什么用、但很有意思的东西。

## 1. PowerShell 和 CMD 是什么？为什么电脑里有两个？

它们都是**接收并执行文字命令的程序**。你输入一句命令，它们负责理解这句话，再调用相应功能或启动程序。这类程序也叫 **Shell**，中文通常叫“命令行解释器”。

**CMD（命令提示符）是 Windows 上较早的一套命令行环境**。它保留了很多 DOS 时代的命令习惯，常用于运行程序、处理文件，以及执行 `.bat` 批处理脚本。你在老教程里看到的黑底白字窗口，很多就是它。

**PowerShell 是微软后来开发的命令行环境，第一版发布于 2006 年**。它也能运行程序、操作文件，同时提供更丰富的脚本和自动化能力，方便把多个操作连起来，让电脑批量完成任务。[微软的 PowerShell 介绍](https://learn.microsoft.com/en-us/powershell/scripting/overview)和[第一版发布记录](https://devblogs.microsoft.com/powershell/its-a-wrap-windows-powershell-1-0-released/)可以帮助你了解它的来历。

先看几个和本节直接相关的区别：

| 对比     | CMD               | PowerShell                |
| ------ | ----------------- | ------------------------- |
| 常见提示符  | `C:\Users\你的用户名>` | `PS C:\Users\你的用户名>`      |
| 清屏     | `cls`             | `cls` 或 `clear`           |
| 脚本文件   | 常见为 `.bat`、`.cmd` | 常见为 `.ps1`                |
| 处理命令结果 | 主要处理文字            | 可以处理带有属性的数据，例如文件名、大小和修改时间 |

下图上方是 PowerShell，下方是 CMD。可以对照窗口标题和提示符，辨认自己打开的是哪一种。

![PowerShell 与 CMD 的窗口及提示符对比](0-6%20图片/01-powershell-and-cmd.png)

许多已有程序和脚本仍然依赖 CMD；PowerShell 则提供更多自动化能力。保留两者，既方便使用旧工具，也方便完成新的任务。[微软的 Windows 命令文档](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/windows-commands)介绍了这两种命令行环境。

它们看起来相似，但语法多有不同。例如，后面用到的 `Get-Random` 是 PowerShell 命令，不能直接放进 CMD 运行。

你还可能遇到 **Windows Terminal（终端）**。它负责提供显示文字、接收键盘输入的窗口，可以在不同标签页里打开 PowerShell 或 CMD；具体理解并执行命令的，仍然是标签页里的那一个 Shell。

这一节建议先用 PowerShell；只适用于 CMD 的例子会单独标出来。

## 2. 一段往事：从敲命令到点鼠标，盖茨和乔布斯在争什么？

### 电脑曾经很需要你“会说它的语言”

在图形界面普及之前，许多电脑用户通过文字终端操作电脑：想查看文件，就输入查看文件的命令；想运行程序，就输入程序名。你得知道能输入什么，也得把命令写对。当时很多终端只能显示单色文字。[计算机历史博物馆对早期交互方式的介绍](https://www.computerhistory.org/revolution/input-output/14/347)展示了这段历史。

下面是 FreeDOS 的命令行界面，展示了 DOS 风格的文字操作方式：输入 `dir`，就能看到文件列表。

![FreeDOS 命令行中运行 dir 查看文件列表](0-6%20图片/02-freedos-command-line.png)

后来，研究者希望让电脑更容易使用：把文件画成图标，把程序放进窗口，让人用鼠标点击。我们今天熟悉的**图形用户界面（GUI）**，就是这样逐步发展起来的。你不必先背出一个命令，也能看到屏幕上有哪些东西可以操作。

这段发展史里，除了苹果和微软，还有一个重要角色：**施乐（Xerox）的帕洛阿尔托研究中心，简称 PARC**。研究者在那里把鼠标、图形显示、窗口等技术组合成了影响深远的电脑交互方式。[计算机历史博物馆：Xerox Alto](https://www.computerhistory.org/revolution/input-output/14/347)

### 乔布斯看到了未来，盖茨也想做图形界面

1979 年，苹果的联合创始人史蒂夫·乔布斯和苹果工程师参观了 Xerox PARC，看到了 Alto 的图形界面。这次参观进一步推动了苹果已经在开展的相关工作。1984 年，苹果推出 Macintosh，把图形界面、图标和鼠标带给更多个人电脑用户。[PARC 与苹果的往事](https://www.computerhistory.org/revolution/story/348)、[Macintosh 四十周年回顾](https://computerhistory.org/exhibits/hello-the-mac-at-40/)

微软的联合创始人比尔·盖茨，当时也和苹果合作：微软为尚在开发中的 Macintosh 编写应用软件。不过，微软同时在开发自己的图形界面环境 Windows。对于苹果来说，这位合作伙伴也正在成为竞争对手。

### 那位叫施乐的“富邻居”

按照早期 Macintosh 开发者 Andy Hertzfeld 的回忆，乔布斯得知 Windows 的计划后，非常愤怒，指责微软模仿苹果。盖茨则用一个“施乐是富邻居、两家都看中了邻居家的电视”的比喻回应，意思是：**苹果和微软都从施乐的研究中得到了启发。**

故事还有后续。1997 年，乔布斯和盖茨宣布苹果与微软达成新的合作：微软继续为 Mac 开发 Office 等软件，并投资 **1.5 亿美元**购买苹果的无投票权股票，双方也达成了专利交叉许可协议。竞争对手仍然有共同的客户和合作的理由。[1997 年双方合作公告](https://news.microsoft.com/source/1997/08/06/microsoft-and-apple-affirm-commitment-to-build-next-generation-software-for-macintosh/)

图形界面普及后，命令行也一直保留着。点击图标很直观；把操作写成命令，则方便重复执行、批量处理，也方便把步骤交给别人或 AI。

接下来我们就打开这个文字入口，试着指挥电脑做几件事。

## 3. 先把命令行打开

### 方法一：从开始菜单打开

1. 按一下键盘上的 `Win` 键，打开开始菜单。
2. 输入 `PowerShell`，点击搜索结果中的 Windows PowerShell 或 PowerShell。
3. 如果想打开 CMD，就搜索 `cmd`，点击“命令提示符”。

### 方法二：用快捷键打开

按 `Win + R`，在弹出的“运行”窗口中输入：

```text
powershell
```

然后按回车。想打开 CMD，就把上面的内容换成 `cmd`。

![在 Win + R 打开的“运行”窗口中输入 powershell](0-6%20图片/03-open-powershell-from-run.png)

### 方法三：直接在一个文件夹里打开

打开文件资源管理器，进入你想操作的文件夹。点击上方地址栏，输入 `powershell` 或 `cmd`，再按回车。

![在文件资源管理器地址栏中输入 CMD](0-6%20图片/04-open-cmd-from-address-bar.png)

这样打开后，命令行的**当前位置就是这个文件夹**，运行里面的代码会很方便。

Windows Terminal（终端）也可以承载 PowerShell 和 CMD。在终端的新标签页菜单里，可以选择要打开哪一种。

## 4. 怎么输入一条命令？

打开 PowerShell 后，通常会看到类似这样的文字：

```text
PS C:\Users\你的用户名>
```

它表示：电脑已经准备好接收命令，你现在位于这个文件夹。

在后面输入：

```powershell
echo "你好，命令行！"
```

按回车后，屏幕上就会出现这句话。恭喜，你已经用文字指挥电脑完成了第一件事。

![PowerShell 中运行 echo 输出“你好，命令行！”](0-6%20图片/05-powershell-echo.png)

**复制本文命令时，只复制代码框里的命令，不要把 `PS C:\...>` 这样的提示符一起复制**。普通命令一行一行运行；后面带有大括号的完整小脚本，可以整块复制。

先记住三个很好用的键：

| 按键         | 作用                            |
| ---------- | ----------------------------- |
| `↑`        | 找回上一条输入过的命令，方便修改后再运行          |
| `Tab`      | 补全命令或文件名；不确定时可以多按几次           |
| `Ctrl + C` | 通常可以中断正在运行的命令或程序；选中文字时可能会执行复制 |

## 5. 最基础、最常用的几个命令

### 清屏：`cls` / `clear`

输出太多、屏幕太乱了？输入：

```powershell
cls
```

在 PowerShell 中，你也可以输入：

```powershell
clear
```

它们会清理当前屏幕上的显示，不会删除你的文件。**CMD 使用 `cls`，默认不支持 `clear`。**

### 看看这里有什么：`dir`

```powershell
dir
```

它会列出当前文件夹里的文件和子文件夹，就像在文件资源管理器里查看列表。PowerShell 和 CMD 都可以使用。

![PowerShell 中运行 dir 列出当前目录的文件和子文件夹](0-6%20图片/06-powershell-dir.png)

### 进入一个文件夹：`cd`

假设你当前的文件夹里有一个叫 `hello` 的子文件夹：

```powershell
cd hello
```

回到上一层文件夹：

```powershell
cd ..
```

也可以直接输入完整地址。下面是 **PowerShell** 的写法，请把地址替换成自己电脑上实际存在的文件夹：

```powershell
cd "D:\我的项目\hello"
```

### 新建一个文件夹：`mkdir`

```powershell
mkdir command-playground
```

它会在当前位置创建一个叫 `command-playground` 的文件夹。接着输入：

```powershell
cd command-playground
```

你就进入了自己的命令行练习场。这两条命令在 PowerShell 和 CMD 中都能使用。

### 用文件资源管理器打开当前位置：`explorer .`

```powershell
explorer .
```

最后的 `.` 表示“当前文件夹”。执行后，会弹出一个文件资源管理器窗口，展示你所在的位置。PowerShell 和 CMD 都可以使用。

![运行 explorer . 后打开当前文件夹的文件资源管理器窗口](0-6%20图片/07-explorer-current-folder.png)

### 退出：`exit`

```powershell
exit
```

退出当前命令行会话。单独打开的窗口通常会关闭；在终端里则通常会关闭对应的标签页。

## 6. 学编程时会反复遇到：`python` 和 `pip`

这部分需要你已经安装 Python。打开 PowerShell 或 CMD，先试试：

```powershell
python --version
```

如果显示 `Python 3.x.x` 这样的版本号，说明这个命令可以使用。

### 安装一个 Python 库：`pip install`

Python 库可以理解为别人写好、供你使用的工具。安装库时，你经常会看到这样的命令：

```powershell
pip install requests
```

这表示：通过 `pip`，下载并安装一个叫 `requests` 的 Python 库。`install` 是安装，最后的 `requests` 是库的名字。安装时通常需要联网。如果你的网络有问题，可以求助 AI Agent，它会帮你找到合适的镜像源。

教程让你安装别的库，就把最后的名字换掉。**`pip` 安装的是 Python 库，不是任意电脑软件。**

更建议你养成下面这个写法的习惯：

```powershell
python -m pip install requests
```

它表示“让当前这个 Python 来运行 pip”，能减少电脑上有多个 Python 时装错位置的问题。先在这里认识写法，之后遇到项目，再按项目的环境要求安装。

查看已经安装的库：

```powershell
python -m pip list
```

### 运行一个 Python 文件

如果当前文件夹里有一个 `hello.py` 文件，就可以输入：

```powershell
python hello.py
```

它会运行这个文件里的代码。这里的 `hello.py` 是示例名字，要换成你实际拥有的文件名。

如果电脑提示找不到 `python`，可以试试 `py --version`。如果 `py` 能用，上面的命令也可以相应改成 `py -m pip install requests`、`py hello.py`。

## 7. 来点好玩的

下面几段不要求你理解每一个符号。先复制、运行、看看效果，再试着修改里面的文字或数字。

### ① 给 CMD 换上 brat 同款配色

**请在 CMD 中运行**，依次输入：

```bat
color 0a
echo Welcome to the Matrix.
```

文字会变成亮绿色，背景变成黑色。你并没有因此获得黑客技能，但气氛已经到了。

![CMD 中运行 color 0a 后显示黑底亮绿色文字](0-6%20图片/08-cmd-green-text.png)

恢复默认颜色：

```bat
color
```

### ② 让 PowerShell 帮你掷骰子

**请在 PowerShell 中运行：**

```powershell
Get-Random -Minimum 1 -Maximum 7
```

每次会得到一个 1 到 6 的整数。这里的上限 `7` 不包含在结果里，所以正好是一颗六面骰子。

也可以让它决定今天吃什么：

```powershell
"海底捞", "滨寿司", "麦当劳", "食堂" | Get-Random
```

不满意？按 `↑` 再按回车，重新抽一次。随机数负责提建议，你负责反悔。

### ③ 在 PowerShell 里做一个打字机效果

**请在 PowerShell 中整块复制并运行：**

```powershell
"你好，欢迎来到 AI 智能体 + 协会。".ToCharArray() | ForEach-Object {
    Write-Host $_ -NoNewline -ForegroundColor Cyan
    Start-Sleep -Milliseconds 100
}
Write-Host
```

这句话会以青色文字，一个字一个字地出现在屏幕上。

把引号里的文字换成你想说的话；把 `100` 改成 `30`，打字会变快，改成 `300` 就会慢下来。随时可以按 `Ctrl + C` 停止。

### ④ 让电脑开口说话

**请在 Windows 的 PowerShell 中运行，先确认音量合适：**

```powershell
$voice = New-Object -ComObject SAPI.SpVoice
$voice.Speak("Hello! Welcome to AI 智能体 + 协会.")
```

电脑会用系统里的语音朗读这句话。你可以修改引号里的内容，也可以试试中文；能否正确朗读中文，取决于电脑安装的语音。

第一行准备一个朗读工具，第二行让它说话。如果系统缺少对应语音组件，这个小彩蛋可能无法运行，可以先玩前面几个。

命令行不一定总是黑底白字、严肃工作。它也可以是一个随手玩玩的小实验室。
