# 0-2-1 如何阅读 Markdown

你现在看到的就是一份 Markdown 文件。

Markdown 文件的扩展名是 `.md`。它本质上是纯文本，但 MarkText、GitHub 等工具会把其中的符号渲染成标题、列表、粗体、链接和代码块。下面每个例子都会先展示**源码写法**，再展示**实际效果**。

## 推荐工具：MarkText

推荐使用 MarkText 阅读 Markdown。它免费、界面简洁，打开 `.md` 文件后会直接显示排版结果，也可以像普通文档一样编辑。

1. 安装并打开 MarkText；
2. 点击 `File` → `Open File`；
3. 选择一个 `.md` 文件；
4. 直接阅读或修改；
5. Windows 按 `Ctrl + S`、macOS 按 `Command + S` 保存。

也可以右键 `.md` 文件，选择“打开方式”→ MarkText，并将它设为默认应用。

如果只是阅读社团资料，也可以直接在 GitHub 中点击 `.md` 文件，网页会自动完成渲染。

## 常见 Markdown 格式

### 1. 标题

源码写法：

```text
# 一级标题
## 二级标题
### 三级标题
```

实际效果：

# 一级标题

## 二级标题

### 三级标题

井号越多，标题层级越低。井号后要留一个空格。

### 2. 列表

无序列表的源码写法：

```text
- 苹果
- 香蕉
- 橙子
```

实际效果：

- 苹果
- 香蕉
- 橙子

有序列表的源码写法：

```text
1. 第一步
2. 第二步
3. 第三步
```

实际效果：

1. 第一步
2. 第二步
3. 第三步

### 3. 粗体和斜体

源码写法：

```text
**这是粗体**

*这是斜体*
```

实际效果：

**这是粗体**

*这是斜体*

渲染后，包围文字的星号不会显示，只会看到排版效果。

### 4. 链接

源码写法：

```text
[MarkText 官网](https://www.marktext.cc/)
```

实际效果：

[MarkText 官网](https://www.marktext.cc/)

方括号里是显示的文字，圆括号里是真正的网址。打开陌生链接前，请确认网址是否可信。

### 5. 图片

源码写法：

```text
![图片说明](图片地址)
```

渲染后，页面会在当前位置显示图片。“图片说明”会在图片无法加载时帮助读者理解内容。

如果图片无法显示，通常是图片不存在、路径写错，或者网络图片无法访问。

### 6. 行内代码

源码写法：

```text
运行 `python main.py` 启动程序。
```

实际效果：

运行 `python main.py` 启动程序。

行内代码通常用来表示命令、文件名、快捷键或较短的代码。

### 7. 代码块

源码写法：

````text
```python
print("Hello, world!")
```
````

实际效果：

```python
print("Hello, world!")
```

复制代码时，只复制代码块里面的内容，不要把上下两行三个反引号一起复制。

### 8. 引用

源码写法：

```text
> 这是一段提示或引用。
```

实际效果：

> 这是一段提示或引用。

## 常见问题

### 为什么双击 `.md` 文件后让我选择应用？

系统还没有为 `.md` 设置默认应用。选择 MarkText，并勾选始终使用该应用即可。

### 为什么我看到很多井号、星号和反引号？

你正在查看 Markdown 源码。用 MarkText 或 GitHub 打开后，就能看到渲染后的排版效果。

### 可以用 Word 打开吗？

不推荐。Word 可能无法正确显示 Markdown，保存时也可能改变文件格式。

### 阅读 Markdown 必须会写 Markdown 吗？

不需要。能认出标题、列表、链接和代码块，就足够阅读大多数社团资料。但我真的希望你会写。
