0-2 如何阅读 Markdown
======================

社团资料中经常会遇到扩展名为 .md 的文件，例如 README.md。
这类文件使用 Markdown 编写。Markdown 是一种轻量级文本格式：文件本身是普通文字，但阅读软件可以把其中的符号显示成标题、列表、链接、图片和代码块。

本节特意使用 .txt 文件保存，确保你即使还不会打开 Markdown，也能先用系统自带的记事本阅读这份说明。


一、推荐工具：MarkText
--------------------

推荐使用 MarkText 阅读 Markdown。它的界面简洁，打开文件后会直接显示排版效果，也可以在正文中修改内容。

基本用法：

1. 安装并打开 MarkText；
2. 点击 File（文件）→ Open File（打开文件）；
3. 选择扩展名为 .md 的文件；
4. 直接阅读排版后的内容；
5. 修改后按 Ctrl + S（Windows）或 Command + S（macOS）保存。

也可以在文件管理器中右键 .md 文件，选择“打开方式”，再选择 MarkText。设为默认应用后，以后双击 .md 文件即可打开。


二、不安装软件也能阅读
----------------------

Markdown 本质上是纯文本，所以没有 MarkText 时也能打开：

- Windows：使用记事本或 Visual Studio Code；
- macOS：使用文本编辑或 Visual Studio Code；
- GitHub：直接点击仓库中的 .md 文件，网页会自动显示排版效果；
- 浏览器：部分浏览器安装 Markdown 扩展后也能预览。

如果只是阅读仓库资料，直接在 GitHub 中查看通常已经足够。


三、认识常见 Markdown 格式
------------------------

1. 标题

井号表示标题，井号越多，标题层级越低：

    # 一级标题
    ## 二级标题
    ### 三级标题

在 MarkText 或 GitHub 中，它们会显示成不同大小的标题。

2. 列表

减号开头表示无序列表：

    - 苹果
    - 香蕉
    - 橙子

数字加英文句点表示有序列表：

    1. 第一步
    2. 第二步
    3. 第三步

3. 强调

    **这是粗体**
    *这是斜体*

4. 链接

    [显示的文字](https://example.com)

点击排版后的文字即可打开链接。打开陌生链接前，请确认网址是否可信。

5. 图片

    ![图片说明](图片地址)

如果图片无法显示，通常是图片文件不存在、路径写错，或者网络图片无法访问。

6. 行内代码

一对反引号可以标记命令、文件名或代码，例如：

    `python main.py`

7. 代码块

代码块通常由上下各三个反引号包围，例如：

    ```python
    print("Hello, world!")
    ```

阅读时不要把代码块前后的三个反引号复制进终端，只复制代码块里面真正的命令。

8. 引用

大于号开头表示引用：

    > 这是一段提示或引用。


四、阅读社团资料时的建议
----------------------

1. 先看标题和目录，了解文档结构；
2. 按顺序阅读操作步骤，不要跳过前置条件；
3. 遇到代码块时，先确认它是示例、配置还是需要执行的命令；
4. 不要直接运行来源不明的命令；
5. 修改文件前保留原意，提交前检查预览效果；
6. 图片看不到时，先检查图片路径和网络；
7. 遇到不懂的术语，记录所在标题和原句，再进行提问。


五、常见问题
------------

问：为什么双击 .md 文件后让我选择应用？
答：系统还没有为 .md 设置默认应用。选择 MarkText，并勾选始终使用该应用即可。

问：为什么我看到很多井号、星号和反引号？
答：你正在以纯文本方式查看 Markdown 源文件。换用 MarkText 或在 GitHub 中打开，就能看到排版效果。

问：可以用 Word 打开吗？
答：不推荐。Word 可能不会正确显示 Markdown 格式，还可能在保存时改变文件内容。

问：阅读 Markdown 必须会写 Markdown 吗？
答：不需要。能认出标题、列表、链接和代码块，就足够阅读大多数社团资料。

问：为什么这份教程不是 .md 文件？
答：这是刻意设计的入口文件。还不会打开 Markdown 的同学，也可以先用任何文本编辑器阅读它。


六、本节练习
------------

1. 用记事本或文本编辑打开本文件；
2. 安装并打开 MarkText；
3. 使用 MarkText 打开同目录下的“0-1 全章节导读.md”；
4. 找出其中的一级标题、二级标题、列表和引用；
5. 回到 GitHub，观察同一个 .md 文件在网页中的显示效果。

完成以上步骤后，你就具备了阅读后续 Markdown 学习资料所需的全部基础。
