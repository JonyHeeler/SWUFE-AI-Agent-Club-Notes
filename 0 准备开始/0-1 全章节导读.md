# 0-1 全章节导读

欢迎来到西南财大 AI 智能体 + 协会的技术分享。

在我们线下见面之前，衷心希望你能掌握第 0 章的工具与知识，这将帮你快速上手，有效降低你的学习与沟通成本。

## 本章内容

### 0-2 如何阅读 Markdown

认识 Markdown 文件，学习使用 MarkText 等工具打开和阅读协会资料，并掌握标题、列表、链接、图片和代码块等常见格式。

### 0-3 电脑上的常见截图方式

分别介绍 Windows 和 macOS 的常见截图方法。

### 0-4 使用 WorkBuddy 配置 VS Code 与 C++

借助 WorkBuddy 安装 VS Code、MSYS2 和 C/C++ 工具链，并完成首次运行。

### 0-5 文件扩展名与文件树

认识文件、文件夹和常见文件扩展名，学会显示 Windows 文件后缀、阅读文件树，并理解绝对路径和相对路径。

### 0-6 使用命令行控制电脑

认识 PowerShell 与 CMD 的区别；学会一些基础命令。

### 0-7 符号这件小事

认识全角、半角和中英文符号的区别，分清代码语法与字符串中的标点，避免新手常见的符号输入错误。

## 学完本章，你应该能够

- 不再用手机拍电脑屏幕
- 能使用 MarkText 等工具阅读 Markdown 文件
- 能配置 C/C++ 开发环境并在 VS Code 中运行程序
- 能看懂文件扩展名与文件树，确认文件位置，并排查相对路径导致的“找不到文件”问题
- 能打开命令行，使用基础命令操作文件夹，并看懂 Python 运行与 pip 安装命令
- 能辨认代码中的常见符号，排查中英文标点和全角半角混用的问题
