# 0-1 全章节导读

欢迎来到 AI Agent 社团技术分享会。

这一章不讲复杂技术，只做一件事：把参加后续分享会前最常用的电脑操作准备好。无论你之前是否接触过编程，只要跟着操作一遍，就能顺利完成资料阅读、问题反馈和作业提交。

## 本章内容

### 0-1 全章节导读

介绍本章的学习目标、内容安排和学习方式，帮助你快速知道应该学什么、做到什么程度。

### 0-2 如何阅读 Markdown

认识 Markdown 文件，学习使用 MarkText 打开和阅读社团资料，并掌握标题、列表、链接、图片和代码块等常见格式。

### 0-3 电脑上的常见截图方式

分别介绍 Windows 和 macOS 的常见截图方法，包括：

- 截取指定区域
- 截取单个窗口
- 截取整个屏幕
- 将截图复制到剪贴板
- 找到截图保存的位置
- 提交一张清楚、有效的截图

## 学完本章，你应该能够

- 不再用手机拍电脑屏幕
- 能使用 MarkText 阅读 Markdown 文件
- 根据需要截取区域、窗口或整个屏幕
- 知道截图保存在哪里
- 将截图粘贴到微信、QQ、飞书、文档或 Issue 中
- 在提问时提供包含关键报错信息的清晰截图
- 主动避开密码、密钥、手机号等隐私信息

## 推荐学习方式

阅读每一节时，请在自己的电脑上同步操作。快捷键看懂不等于会用，亲手截一张图、保存一次、粘贴一次，才算完成。

如果操作结果和文档不同，先确认自己的操作系统，再向同学或负责人提问。提问时请说明：

1. 你使用的是 Windows 还是 macOS；
2. 你按了哪些键；
3. 你期望出现什么；
4. 实际出现了什么；
5. 附上一张清晰截图。

> 从这一章开始，除非电脑完全无法显示，否则请不要再用手机拍电脑屏幕。
