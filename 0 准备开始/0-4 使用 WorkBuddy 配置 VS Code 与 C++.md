# 0-4 使用 WorkBuddy 配置 VS Code 与 C++

> 本文的作者是奇点工作室 秋霖霜。

## 初始准备

下载 WorkBuddy 并注册账号。

## 使用 WorkBuddy 完成配置

让 WorkBuddy 依次完成以下操作。可以选择倍率较高的模型，以提高操作稳定性。

1. 安装 VS Code 并添加环境变量。可以安装到 D 盘；随后安装中文插件和 C/C++ 插件。
2. 安装 MSYS2，也可以安装到 D 盘。
3. 在 MSYS2 中安装 C/C++ 工具链，并添加环境变量。这一步可能需要等待一段时间。

## 手动操作

如果遇到问题，可以把问题尽量详细地描述给 WorkBuddy，寻求帮助。

4. 重启电脑，新建一个存放代码的文件夹。打开该文件夹，右键选择“通过 Code 打开”；也可以先启动 VS Code，再打开该文件夹。

   ![右键菜单中的“通过 Code 打开”选项](<0-4 图片/image1.png>)

5. 如果 VS Code 左下角显示“受限模式”，点击它并选择“信任”。如果没有显示，可以跳过这一步。

   ![VS Code 左下角的受限模式入口](<0-4 图片/image2.png>)

   ![工作区信任界面中的“信任”按钮](<0-4 图片/image3.png>)

6. 点击右上角的运行按钮，选择“运行 C/C++ 文件”，再选择 g++（用于 C++）或 gcc（用于 C）。

   ![VS Code 右上角的运行 C/C++ 文件选项](<0-4 图片/image4.png>)

   ![选择 C/C++ 编译器](<0-4 图片/image5.png>)

7. 确认下方显示的是“终端”，然后就可以在终端中输入内容。

   ![VS Code 的终端界面](<0-4 图片/image6.png>)
