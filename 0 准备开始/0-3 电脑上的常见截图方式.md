# 0-3 电脑上的常见截图方式

遇到报错或需要展示电脑界面时，请直接截图，不要用手机拍屏幕。截图更清楚，也方便别人放大、保存和查看文字。

## Windows

按下面任意一个快捷键：

```text
Windows + Shift + S
```

或：

```text
Print Screen
```

`Print Screen` 在键盘上也可能写作 `PrtSc` 或 `PrtScn`。部分笔记本电脑需要同时按住 `Fn`。

在目前常见的 Windows 设置中，这两个快捷键都会打开截图工具。屏幕变暗后：

1. 按住鼠标左键框选需要的区域；
2. 松开鼠标完成截图；
3. 在微信、QQ、飞书或文档中按 `Ctrl + V` 粘贴。

如果按 `Print Screen` 没有打开截图工具，直接使用 `Windows + Shift + S`。

需要截取整个屏幕时，可以按：

```text
Windows + Print Screen
```

图片通常保存在“图片”文件夹下的“屏幕截图”中。

## macOS

截取指定区域：

```text
Command + Shift + 4
```

按住鼠标或触控板框选区域，松开后完成截图。图片默认保存在桌面。

截取整个屏幕：

```text
Command + Shift + 3
```

如果希望截图只进入剪贴板，在截图快捷键中额外按住 `Control`，然后按 `Command + V` 粘贴。

## 怎样截一张有用的图

- 保留完整报错和必要的上下文，不要只截“失败”两个字；
- 只截相关区域，不要把整个桌面和聊天记录一起发出；
- 发出前检查姓名、学号、手机号、密码和 API Key 等隐私；
- 确认图片方向正常，文字清晰可读；
- 截图之外，再用一句话说明你做了什么、期望什么、实际发生了什么。
