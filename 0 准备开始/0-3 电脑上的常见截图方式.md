# 0-3 电脑上的常见截图方式

遇到报错或需要展示电脑界面时，请直接截图，不要用手机拍屏幕。截图更清楚，也方便别人放大、保存和查看文字。

## Windows

按下面任意一个快捷键：

```text
Windows + Shift + S
```

或：

```text
Print Screen
```

`Print Screen` 在键盘上也可能写作 `PrtSc` 或 `PrtScn`。部分笔记本电脑需要同时按住 `Fn`。

在目前常见的 Windows 设置中，这两个快捷键都会打开截图工具。屏幕变暗后：

1. 按住鼠标左键框选需要的区域；
2. 松开鼠标完成截图；
3. 在微信、QQ、飞书或文档中按 `Ctrl + V` 粘贴。

图片通常保存在文件管理器“图片”文件夹下的“屏幕截图”中。

## macOS

截取指定区域：

```text
Command + Shift + 4
```

按住鼠标或触控板框选区域，松开后完成截图。图片默认保存在桌面。

截取整个屏幕：

```text
Command + Shift + 3
```

如果希望截图只进入剪贴板，在截图快捷键中额外按住 `Control`，然后按 `Command + V` 粘贴。

**能截图，就不要拍屏幕。谢谢大家，也谢谢我们的眼睛。**
