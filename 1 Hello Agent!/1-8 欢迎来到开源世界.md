# 1-8 欢迎来到开源世界

**开源，就是把软件的源代码公开，并通过许可证允许别人使用、研究、修改和再分发。**

众多计算机科学家与优秀开发者从上世纪到现在，选择公开自己的代码、分享技术经验，让来自世界各地的人能够学习、使用并继续改进他们的成果。一代人留下的工具，成为下一代人创造的起点；一个人解决的问题，也能帮助无数素未谋面的人。欢迎来到开源世界，在接下来的工作和学习中，你会无数次赞叹开源精神的伟大，同时：**你也有能力为开源世界做出贡献！**

开源世界令人敬佩，主要因为它让知识和成果可以不断积累。

- **让学习越过“只看效果”的阶段**。你可以使用一个工具，也可以打开代码，看看它怎样实现。对初学者来说，真实项目提供了课本之外的例子。
- **让人站在已有成果上继续创造**。别人已经解决的问题，可以在遵守许可的前提下复用。开发者因此能把精力用在新的问题上。
- **让陌生人能够共同建设**。有人写功能，有人修错误，有人翻译文档，也有人认真报告问题。这些贡献汇集起来，可能成为很多人每天依赖的工具。
- **让软件有机会被检查和延续**。公开代码方便他人审查实现、发现问题。即使原作者停止维护，其他人也可能接手，或基于它继续开发。

比如，你做出了一个课堂抽签器，把代码、使用说明和许可证一起公开。另一所学校的同学发现了重复抽取的问题，提交修复；后来又有人补上键盘操作和英文界面。**你最初解决的是自己班级的小问题，合作却让成果帮助了更多人。**

这一节我们先进入开源世界，先学会找有助于你工作和学习的项目。

## 1. Git、GitHub、仓库分别是什么？

| 名词                    | 可以先怎样理解             |
| --------------------- | ------------------- |
| Git                   | 记录和管理文件版本的工具，这一节用不到 |
| GitHub                | 托管项目、进行协作的平台        |
| 仓库（Repository / Repo） | 一个项目的文件及其版本记录的集合    |
| README                | 项目说明，常介绍用途、安装与运行方式  |
| LICENSE               | 使用、修改和分发项目时应遵守的许可   |

**Git 是 Linux 的创始人林纳斯·托瓦兹（Linus Torvalds）在 2005 年创建的版本管理工具。它最初是为了解决 Linux 内核开发中的协作问题。**

Linux 内核由分布在世界各地的开发者共同维护。每天都有许多人修改代码，项目需要记录：谁改了什么、为什么修改，以及不同人的修改怎样合并。出现问题时，还要能找回之前的版本。

Linux 开发团队曾使用 BitKeeper 管理代码。2005 年，围绕它的使用与许可发生争议，原有的免费使用安排结束。托瓦兹于是决定开发一个符合团队需求的新工具，这就是 Git。

他特别看重三个方面：

- **速度快**：能高效处理 Linux 内核这样的大型项目。
- **分布式协作**：每位开发者都可以拥有完整的版本历史，在自己的电脑上提交修改，再与别人交换成果。
- **保护历史的完整性**：通过内容校验等机制，让历史内容的变化可以被识别和追踪。

Git 还让开发者方便地创建**分支**：先在一条独立的开发线上尝试功能，成熟后再合并回主线。这让多人同时工作更容易组织。

后来，Git 成为开源项目，由社区持续维护，滨野纯（Junio C Hamano）长期担任主要维护者。**GitHub 则是在 2008 年出现的，它围绕 Git 提供代码托管和协作服务**。你可以在上面保存项目、查看修改历史、报告问题，也可以参与别人公开的项目。**所以，Git 先于 GitHub 存在，离开 GitHub 也可以使用。**

## 2. 如何找到你想要的东西？

在 GitHub 中搜索功能关键词，例如 `pomodoro`（番茄钟）、`random picker`（随机抽签）、`personal homepage`（个人主页）。可以加上 `HTML` 或 `JavaScript` 缩小范围。

选择 **Repositories（仓库）** 结果。也可以直接搜索中文；下图以“数学建模”为例，左侧选中了“仓库”，右侧会列出各个项目的名称、简介和相关信息。

![在 GitHub 搜索“数学建模”，左侧选择仓库结果](1-8%20图片/01-github-search-repositories.png)

打开项目后，先读 README：

- 这个项目解决什么问题，是否正好适合当前任务？
- 是否需要安装环境、运行服务或注册账号？
- 有没有运行示例、使用说明和已知限制？
- 最近是否有人维护，遇到的问题是否有记录？
- LICENSE 允许怎样使用和修改？

Star 数量可以参考，但不能单独证明安全、质量或适用性。

下图是协会资料仓库的 README。仓库首页往下滚动，就能阅读这样的项目说明；先了解用途和使用方法，再决定是否下载。

![协会资料仓库首页展示 README，包括资料用途和学习建议](1-8%20图片/02-github-readme.png)

## 3. 下载整个项目：Code → Download ZIP

1. 打开仓库首页，确认自己要下载的分支。
2. 在文件列表上方找到 **Code**，选择 **Download ZIP**。
3. 下载完成后，把整个压缩包解压到自己的练习目录。
4. 先读 README，再按要求打开或运行。

下图展示了协会仓库的下载入口。中文界面中的绿色按钮显示为“代码”，展开后选择底部的“下载 ZIP 压缩包”。

![展开 GitHub 的代码菜单，选择下载 ZIP 压缩包](1-8%20图片/03-github-download-zip.png)

ZIP 是所选分支当时内容的快照，不包含完整 Git 版本历史，也不会随着远程更新自动变化。

**下载源码不等于安装软件。** 如果你只想使用现成应用，先看 README 是否指向 Releases（发布版本）中的安装包。

## 4. 只拿一个文件：Raw 或下载按钮

进入具体文件页，使用“下载原始文件”按钮；或打开 **Raw** 视图，再保存原始内容。按钮位置可能随界面版本变化。

下图以协会的一篇 Markdown 资料为例：文件内容区域右上角的向下箭头，就是“下载原始文件”。旁边的“源码”按钮对应 Raw 视图。

![GitHub 文件页右上角的源码按钮和下载原始文件按钮](1-8%20图片/04-github-download-file.png)

保存后确认后缀正确，例如 `index.html`，不是 `index.html.txt`。

先检查文件是否引用了其他资源。下面这个页面需要同时保留 CSS 和图片：

```text
example/
├── index.html
├── styles/
│   └── style.css
└── images/
    └── firefox-icon.png
```

只下载 HTML，就可能出现没有样式或缺图。文件之间的相对位置也应保持一致。不确定需要哪些文件时，先下载整个项目。

## 5. 选学：clone 是建立本地副本

复制仓库地址，只是把地址放进剪贴板。已经安装 Git 的同学，可以在自己的练习目录打开终端，执行：

```powershell
git clone https://github.com/mdn/beginner-html-site-styled.git
```

这会创建 `beginner-html-site-styled` 文件夹，取回项目及版本记录。若同名文件夹已经存在，换一个空目录操作，不要直接删除原文件夹。

不熟悉 Git 时，用 ZIP 就能完成本节。

不会没关系，你可以让 Coding Agent 帮你。

## 6. 实操：打开 MDN 的示例网站

使用 [MDN 初学者示例仓库](https://github.com/mdn/beginner-html-site-styled)：

![MDN 初学者示例仓库首页，展示 images、styles、index.html 和 README 等文件](1-8%20图片/05-mdn-example-repository.png)

上图中，`images` 存放图片，`styles` 存放样式，`index.html` 是网页入口。可以对照文件列表完成下面的操作。

1. 在 README 中找到项目用途，确认这是用于学习 HTML 与 CSS 的简单网页。
2. 检查 LICENSE；下载 ZIP 并完整解压。
3. 找到 `index.html`、`styles` 和 `images`。
4. 用浏览器打开 `index.html`，观察页面是否正常。
5. 在副本里用编辑器修改标题，保存并刷新；原有许可和署名应保留。

这个示例可以直接打开，但其他项目应按各自 README 操作。在本仓库根目录下的 `.\1 Hello Agent!\source\beginner-html-site-styled-main` 里，我准备了这个仓库的源代码。进入这个文件夹，用浏览器打开 `index.html`；也可以点击[示例网页入口](<source/beginner-html-site-styled-main/index.html>)。

如果你看不懂 `.\1 Hello Agent!\source\beginner-html-site-styled-main` 这样的路径，请回到 [0-5 文件扩展名与文件树](<../0 准备开始/0-5 文件扩展名与文件树.md>)，复习文件树和相对路径的读法。
