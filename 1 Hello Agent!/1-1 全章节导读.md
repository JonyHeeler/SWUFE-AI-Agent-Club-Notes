# 1-1 全章节导读

这一章从认识 AI 开始，逐步讲清怎样提需求、网页怎样工作、Agent 怎样调用工具，再用 WorkBuddy 完成一个小作品，最后学习从开源项目中获取资料和代码。

不要求你提前掌握编程语法，但需要能找到文件、打开文件夹，并使用浏览器和编辑器。如果这些操作还不熟悉，可以先看[第 0 章全章节导读](<../0 准备开始/0-1 全章节导读.md>)。

## 本章内容

### [1-2 认识 AI：能力、原理与边界](<1-2 认识 AI：能力、原理与边界.md>)

分清人工智能、机器学习、深度学习和大语言模型，初步理解语言模型的生成方式。结合数学、生物、天气预测和机器人案例认识 AI 的能力，再通过鹈鹕测试观察不同模型生成图形的差异。

### [1-3 如何给 AI 提需求](<1-3 如何给 AI 提需求.md>)

用课堂抽签器说明怎样补全使用对象、目标、输入、限制和验收标准。认识最小可行产品（MVP），学会拆分任务、描述问题，并理解使用 AI 时仍然需要哪些技术判断。

### [1-4 你的第一个小网页](<1-4 你的第一个小网页.md>)

认识 HTML、CSS 与 JavaScript 分别负责的内容、外观和交互。保存并打开一个最小网页，尝试修改标题和颜色，再分清前端、后端与服务器的作用。

### [1-5 API、Token、上下文与密钥](<1-5 API、Token、上下文与密钥.md>)

理解程序之间怎样通过 API 使用服务，模型怎样用 Token 处理文字，上下文包含哪些材料，以及 API Key 为什么需要保密。

### [1-6 模型、客户端与 Agent](<1-6 模型、客户端与 Agent.md>)

理清模型、客户端和 Agent 的分工，理解 Agent 如何观察、规划、调用工具并根据结果调整。认识 Prompt 和模型幻觉，知道怎样提供任务信息、核对输出。

### [1-7 用 WorkBuddy 完成第一个小工具](<1-7 用 WorkBuddy 完成第一个小工具.md>)

在独立工作文件夹中创建课堂抽签器，找到并打开实际生成的文件，按清单检查功能，练习反馈问题和小步改进。也可以选择专注计时器或个人名片作为作品。

### [1-8 欢迎来到开源世界](<1-8 欢迎来到开源世界.md>)

认识开源的意义、Git 的由来，以及 GitHub 和仓库的作用。学会搜索项目、阅读 README、下载 ZIP 和单个文件，最后打开 MDN 的示例网站。

# 

## 学完本章，你应该能够

- 说明 AI、语言模型、客户端与 Agent 的关系，以及工具在其中的作用。
- 把一个想法写成目标、规则、限制和验收标准明确的需求。
- 指出网页中负责内容、外观和交互的部分。
- 理解 API、Token、上下文和密钥各自的用途。
- 完成一个能打开、能操作的小作品，并清楚描述遇到的问题。
- 从 GitHub 获取项目，读懂基本说明，找到运行入口和所需文件。
