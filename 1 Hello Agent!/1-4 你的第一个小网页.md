# 1-4 你的第一个小网页

这一章先做一个能在本机浏览器里使用的小工具。理解内容、外观、交互分别由谁负责，就能更准确地向 AI 提出修改要求。

## 1. 从文件到网页

网页文件通常也是文本文件。用 VS Code 打开 `.html`，看到的是代码；用浏览器打开，看到的是浏览器解释这些代码后的页面。

```text
在编辑器修改 index.html
          ↓ 保存
在浏览器打开或刷新
          ↓
看到页面，操作按钮，检查结果
```

**编辑后要保存，浏览器中要刷新**。只改编辑器里的内容，没有保存到文件，浏览器通常仍然显示旧版本。

文件名应是 `index.html`，而不是 `index.html.txt`。不确定时，回看[文件扩展名与文件树](<../0 准备开始/0-5 文件扩展名与文件树.md>)。

## 2. 三种技术，各自负责什么？

| 技术         | 职责      | 抽签器里的例子            |
| ---------- | ------- | ------------------ |
| HTML       | 组织内容与结构 | 标题、名单输入框、抽签按钮、结果区域 |
| CSS        | 设置外观与布局 | 字号、颜色、间距、手机屏幕下的排列  |
| JavaScript | 实现交互与逻辑 | 读取名单、去重、抽取、更新记录    |

例如，“按钮改成蓝色”主要涉及 CSS；“空名单时提示”主要涉及 JavaScript，也需要页面上有放提示的位置。

HTML 是标记语言，CSS 是样式表语言，JavaScript 是编程语言。它们经常配合使用，也可以写在同一个 HTML 文件中。

## 3. 亲手改一个最小网页

在自己的练习文件夹中新建 `hello.html`，将下面内容完整保存进去，再用浏览器打开。不要覆盖其他练习文件。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>我的第一个网页</title>
  <style>
    body { font-family: sans-serif; padding: 24px; }
    button { background: #4268bd; color: white; padding: 12px 20px; }
  </style>
</head>
<body>
  <h1>你好，同学！</h1>
  <p id="message">这是一个本地网页。</p>
  <button id="greet">打个招呼</button>
  <script>
    document.getElementById('greet').addEventListener('click', () => {
      document.getElementById('message').textContent = '你已经完成了第一次交互！';
    });
  </script>
</body>
</html>
```

观察三个位置：

- `<h1>`、`<p>`、`<button>` 放标题、段落和按钮。
- `<style>` 里设置样式。
- `<script>` 里规定点击按钮后做什么。

试着把标题改成自己的昵称、把按钮背景改成另一种颜色。保存、刷新，再点击按钮，确认修改没有破坏交互。

## 4. 前端、后端和服务器

**前端**是面向使用者的界面及相关交互逻辑，网页前端通常运行在浏览器中。**后端**处理共享数据、业务规则、身份验证等任务，通常运行在服务器上。服务器可以指提供服务的计算机，也可以指提供服务的软件。它不一定是一台很大的专用设备：自己的电脑也可以运行本地服务。

以点餐为例：

```text
前端：选菜、点击下单
      ↓ 请求
后端：检查库存、保存订单
      ↓ 响应
前端：显示下单结果
```

本地抽签器只要在当前页面里处理名单，不需要后端。如果你后续要实现多人共享名单、跨设备保存记录等需求，才需要进一步考虑服务和数据存储。
