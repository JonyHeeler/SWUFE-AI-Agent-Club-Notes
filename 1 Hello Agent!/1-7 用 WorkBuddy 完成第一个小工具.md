# 1-7 用 WorkBuddy 完成第一个小工具

这一节把前面的概念串起来：给出需求，让 Agent 创建文件，打开网页，检查功能，再修复一个具体问题。

默认作品是课堂抽签器。也可以选择后面的计时器或个人名片，**一次完成一个作品即可**。

## 1. 准备一个独立文件夹

1. 确认 WorkBuddy 已安装并能正常登录。
2. 创建一个空文件夹，例如 `D:\code\first-tool`。没有 D 盘，可以放在文档目录等自己方便找到的位置。
3. 在 WorkBuddy 新建任务，选择这个文件夹作为工作空间，核对显示的路径。
4. 阅读它要执行的操作和授权范围；只处理本次练习需要的目录。

## 2. 发送一份完整需求

将下面这段说明复制给 WorkBuddy。它包含功能、限制和验收要求，可以直接使用。

```text
我是零基础新生，请在当前课堂工作文件夹中创建一个课堂抽签器。
请实际写入完整的 index.html，不要只在聊天里贴代码。

功能：
1. 一个多行文本框，每行一个昵称，默认填入 4 个虚构昵称。
2. 去掉每行首尾空格、忽略空行，同名昵称只保留一次。
3. 点击“开始抽签”，随机显示当前名单中的 1 人。
4. 空名单不抽取，显示“请先输入名单”。
5. 提供“不重复抽取”开关，默认开启；同一轮每人最多抽中一次。
6. 全部抽完后提示“本轮已结束”。提供“重置记录”按钮。
7. 修改名单后清空本轮记录；显示已抽取记录。
8. 如果有抽签动画，最多 1 秒，过程中禁止重复触发。

限制：
- HTML、CSS、JavaScript 全部放在同一文件里，使用系统字体。
- 中文界面，排版清楚，按钮明显，长昵称可换行，窄窗口可使用。
- 不引用网络图片、字体、CDN、第三方库或外部 API。
- 不需要后端、登录、数据库、API Key，也不安装额外依赖。
- 生成的网页能用 Edge 或 Chrome 直接打开，断网后仍能操作。
- 只在当前工作文件夹中操作；发现已有同名文件时先询问，不覆盖其他文件。

验收：
检查空名单、只有一人、重复昵称、全部抽完、重置、修改名单、
连续点击、长昵称与窄窗口。

完成后给出完整文件路径、打开方式、实际执行的检查及结果。
没有运行的检查请明确写“未测试”。
```

## 3. 打开实际文件

找到它给出的 `index.html`，用 Edge 或 Chrome 打开。若双击进入 VSCode 等代码编辑器，请你右键选择“打开方式”，再选浏览器。

看到页面后，先操作核心功能，再考虑如何优化配色和动画。

## 4. 逐项验收并记录结果

| 检查项  | 操作                    | 应看到的结果          |
| ---- | --------------------- | --------------- |
| 空名单  | 删除全部昵称，仅留空格或空行后抽签     | 提示先输入名单，不显示抽中结果 |
| 一人名单 | 只输入“小林”，抽取两次          | 首次为小林，之后提示本轮结束  |
| 去重   | 输入小林、小周、小林，每行一个，开启不重复 | 名单按两人处理，最多抽出两人  |
| 不重复  | 输入三个不同昵称，连续完成三次抽取     | 三人各出现一次，第四次提示结束 |
| 重置   | 抽完后点击“重置记录”，再抽        | 记录清空，可以重新抽取     |
| 改名单  | 抽取后换成新名单              | 旧记录清空，只从新名单抽取   |
| 允许重复 | 关闭“不重复抽取”，多次抽取        | 可以持续抽取；结果始终来自名单 |
| 快速点击 | 抽取过程中连续点击按钮           | 不出现多次并发抽取或混乱记录  |
| 显示   | 输入长昵称，缩窄浏览器窗口         | 文字换行，按钮和结果仍可操作  |
| 离线   | 临时断开网络后重新打开生成的网页      | 名单输入、抽取和重置仍能使用  |

有点麻烦？其实一些优秀的 Agent 可以代劳。你试试？

## 5. 出问题时，怎样继续问？

把下面的括号内容换成自己的实际情况，再发送：

```text
请先阅读当前工作文件夹中的 index.html，定位这个问题。

操作步骤：【输入了什么，按什么顺序点击】
预期结果：【按原需求应该怎样】
实际结果：【现在看到了什么】
报错原文或截图：【有则附上，没有就写未看到报错】

只修复这个问题，保留已有功能，不重建整个项目。
保持单文件、离线可用，不增加依赖或外部 API。
修复后说明原因、改动位置，以及应该重新检查的操作。
未实际执行的测试请标明。
```

浏览器出现异常时，可以按 `F12` 打开开发者工具，查看 Console（控制台）中的错误。复制错误时保留原文，截图中隐藏个人信息。没有报错也可能存在功能问题，应继续提供复现步骤。

## 6. 第一版通过后，只做一个改进

例如：“在抽签完成时添加一个简短庆祝动画，保留原有规则，减少动态效果设置下关闭动画。”

改完重新测试抽取、重置和连续点击。这样可以看出，这次修改有没有影响已经可用的功能。

## 7. 可选作品

如果你不想做抽签，你也可以选择下列两个作品。快来试试！

### 专注计时器

- 输入单位为秒，默认 1500 秒，提供“10 秒测试”；只接受 1～3600 的整数。
- 显示“分:秒”，支持开始、暂停或继续、重置。
- 连续点击开始不能出现多个计时循环；以实际经过时间计算剩余时间。
- 暂停时停止倒计时，归零后提示完成，不出现负数。
- 运行中不能直接修改时长；重置后可重新设置。重置返回所设时长并停止。
- 验收：10 秒归零、暂停等待 3 秒后数字不变、继续、重置、连续点击开始、输入空值或负数。

### 个人名片

- 使用虚构昵称、一句介绍和 3 个兴趣标签，不使用真实照片、学号、电话等资料。
- 输入框修改昵称时，名片实时更新；空昵称显示“新同学”，长昵称换行。
- 支持深浅主题切换，两种主题下文字都能清楚辨认。
- 验收：修改昵称、清空昵称、输入长昵称、切换主题、缩窄窗口。
