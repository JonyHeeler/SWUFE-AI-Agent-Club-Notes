# 苏小铁三维展示

Vite + React + Three.js 源码，支持拖动旋转、缩放、自动旋转、复位及键盘操作。保留源代码、测试、依赖锁定文件与素材来源说明。

安装 Node.js 20.19+ 或 22.12+ 后，在本目录执行：

```powershell
npm ci
npm run dev
```

也可以双击现有的 `启动网页.cmd`。按终端给出的本地地址打开；关闭运行进程会停止服务。

```powershell
npm test
npm run build
```

构建输出为 `dist/`，已被 Git 忽略。校徽来源见 `src/assets/来源说明.md`。人偶为根据照片进行的几何重建，并非原厂模型；人偶形象与校徽属于原权利人。
